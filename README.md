# Bealatriz Pilates Studio — Sitio web

Sitio estático (HTML + CSS + JS), separado y ordenado.

## Estructura
```
Bealatrizwebsite/
├── index.html        # Estructura / contenido (HTML)
├── css/
│   └── styles.css    # Todos los estilos
├── js/
│   └── main.js       # Scripts (header al scroll, menú mobile)
└── assets/
    └── hero.jpg      # (poner acá) foto del hero + fotos de galería
```

## Cómo verlo
Abrí `index.html` en el navegador (doble clic).

## Notas
- Fuentes: Cormorant Garamond + Jost (se cargan desde Google Fonts en el `<head>`).
- El botón "Book" enlaza a la app de reservas: https://da.gd/bealatriz
- Placeholders a completar: dirección, ciudad, horarios, WhatsApp, Instagram y fotos.
- Idioma: inglés.
